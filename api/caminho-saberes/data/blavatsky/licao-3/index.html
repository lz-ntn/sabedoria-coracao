Lição 3: CSS Básico

Dando forma e beleza aos conceitos

O que é CSS?

CSS (Cascading Style Sheets) é a linguagem que define a apresentação visual das páginas web. Assim como um artista usa cores e formas para manifestar sua visão, o CSS transforma a estrutura HTML em algo visualmente significativo.

Conceito Teosófico: A Manifestação da Forma

Na Teosofia, existe o mundo das formas - onde a essência espiritual se manifesta em matéria. O CSS é like ao "Maya" ou "Ilusão cósmica" que dá forma ao que antes era apenas ideia. O conteúdo (HTML) é a essência; o estilo (CSS) é a manifestação.

Seletores - Escolhendo os Elementos

Seletores escolhem quais elementos estilizar. Na meditação, escolhemos em que concentrar - nosso objeto de foco:

seletor { propriedade: valor; } Sintaxe básica
h1 { color: blue; } Seleciona todos os h1
.classe { font-size: 16px; } Seleciona por classe
#id { margin: 10px; } Seleciona por ID

Cores - As Cores da Consciência

CSS permite usar cores de várias formas. Na visão teosófica, cada cor representa um nível vibratório:
