Primeiros Passos com linguagem de marcação

O que é HTML?

HTML (HyperText Markup Language) é a linguagem base para criar páginas web. Assim como a Teosofia busca sintetizar verdades de várias tradições, o HTML serve como fundamento que outras tecnologias web se constroem.

Conceitos Teosóficos: A Unidade de Toda a Vida

Um dos princípios fundamentais da Teosofia é que toda a vida é essencialmente una. No HTML, assim como todas as páginas web compartilham a mesma linguagem base, todas as tradições espirituais apontam para uma mesma verdade fundamental.

Elementos Básicos do HTML

<h1> até <h6> - Títulos

As tags de título (<h1>, <h2>, ...) organizam o conteúdo em níveis de importância, assim como a hierarquia dos seres духов na filosofia teosófica:

Título nível 1 - O Absoluto

Título nível 2 - A Alma Universal

Título nível 3 - Hierarquias Espirituais

Título nível 4 - A Mente Divina

Título nível 5 - O Eu Superior
Título nível 6 - A Personalidade

<p> - Parágrafos

A tag <p> define parágrafos de texto. Cada parágrafo é como uma reflexão em nosso estudo teosófico - desenvolve uma ideia completa antes de passar para a seguinte.

<ul>, <ol> e <li> - Listas

Listas organizam informações. Na Teosofia, os três objetivos da Sociedade Teosófica podem ser представлены assim:

Lista não ordenada (ul):

  • Fraternidade Universal
  • Estudo Comparado das Religiões
  • Investigação da Natureza

Lista ordenada (ol):

  1. Formar o núcleo da fraternidade
  2. Encorajar o estudo comparado
  3. Investigar leis não explicadas

Exemplo Prático: Os Sete Princípios do Homem

Na Teosofia, o ser humano é visto sob sete aspectos. Vamos representá-los em HTML:

                        
                        <ul>
                            <li>Atma - O Espírito Divino</li>
                            <li>Buddhi - A Alma Espiritual</li>
                            <li>Manas - A Mente</li>
                            <li>Kama - Desejo/Vontade</li>
                            <li>Linga Sharira - Corpo Astral</li>
                            <li>Prana - Princípio Vital</li>
                            <li>Sthula Sharira - Corpo Físico</li>
                        </ul>

Resultado visual:

  • Atma - O Espírito Divino
  • Buddhi - Alma Espiritual
  • Manas - Mente
  • Kama - Desejo/Vontade
  • Linga Sharira - Corpo Astral
  • Prana - Princípio Vital
  • Sthula Sharira - Corpo Físico
