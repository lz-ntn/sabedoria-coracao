Lição 2: HTML Semântico

Estruturando com significado

O que é HTML Semântico?

HTML semântico usa elementos que descrevem claramente seu propósito. Na Teosofia, existe uma hierarquia de seres espirituais - cada um com função específica. Assim como cada nível hierárquico tem seu papel, cada tag semântica tem seu propósito definido.

Conceito Teosófico: As Hierarquias Setenárias

Blavatsky fala de sete hierarquias de seres espirituais, cada uma com função específica. Da mesma forma, o HTML semântico define七大 funções distintas para estruturar página:

<header> - O Cabeçalho

Define o cabeçalho de uma página ou seção. É como o "Aspecto Divino" - a essência que norteia tudo que vem depois. 

<header>
  <h1>Título da Página</h1>
  <p>Subtítulo explicativo</p>
</header>

<nav> - Navegação

Define links de navegação. É como o "Caminho" ou "Mestre" que guia o estudante através das diferentes etapas do estudo.

Início Estudo Meditação Serviço

<main> - Conteúdo Principal

Define o conteúdo principal. É o "Eu Superior" - o núcleo verdadero da página, onde a essência do ensinamento se manifesta.

<article> - Artigo Independente

Define um conteúdo independente e autocontido. Cada artigo é como um "ensaio" ou "reflexão" que pode ser compreendido isoladamente.

<section> - Seção Temática

Define uma seção temática. Cada seção organiza ensinamentos relacionados, como os capítulos de um livro de estudo.

<aside> - Conteúdo Relacionado

Define conteúdo relacionado ao redor do conteúdo principal. São como "notas de rodapé" ou "comentários" que complementam o estudo.

<footer> - Rodapé

Define o rodapé da página. É o "retorno" ou "conclusão" - o resultado pratique do estudo.

Exemplo Prático: Estrutura de um Estudo Teosófico

Vamos estruturar uma página completa de estudo:

<header>
<nav>
<main>
<article>
<section>
<aside>
<footer>

Exercício Proposto

  1. Crie uma página chamada "reencarnacao.html"
  2. Use <header> com o título "A Lei da Reencarnação"
  3. Use <nav> com links para diferentes seções do texto
  4. Use <main> contendo <article> para cada conceito
  5. Use <section> para organizar os artigos por temas
  6. Use <aside> para notas e referências
  7. Use <footer> com informações de conclusão
