# Meditação — Autoconhecimento

Site estático para meditação e autoconhecimento com técnicas dos chakras.

## Estrutura

- `index.html` — Página principal com técnicas
- `css/estilo.css` — Estilos personalizados
- `js/main.js` — Interatividade
- `audio/` — Áudios para meditação (frequências Solfeggio)
- `img/` — Imagens do site

## Tecnologias

- HTML5 semântico + Bootstrap 5 + Bootstrap Icons
- CSS3 com variáveis, animações e design responsivo
- JavaScript vanilla
